# Learn Graphs with Raphael

An interactive C++ application for learning graph algorithms through guided, visual sessions. Raphael, the learner's companion, explains each idea, walks through every step, and offers small challenges along the way.

## Learning goals

The first release focuses on three foundational algorithms:

- **Breadth-first search (BFS)** — explore a graph level by level using a queue.
- **Depth-first search (DFS)** — follow paths deeply using recursion or a stack.
- **Dijkstra's algorithm** — find shortest paths in graphs with non-negative edge weights.

Rather than only showing final answers, each session will make the algorithm's choices visible: which vertex is considered, which data structure changes, which edge is explored, and why.

## Planned experience

1. Choose or create a graph.
2. Start a lesson with Raphael.
3. Advance through the algorithm one operation at a time, or let it play automatically.
4. Inspect the queue, stack, visited vertices, distances, and predecessor links as they change.
5. Complete short interactive questions before moving on.

## Project direction

- **Language:** C++
- **Focus:** approachable, interactive algorithm education
- **Core concepts:** directed and undirected graphs, weighted edges, graph traversal, and shortest paths
